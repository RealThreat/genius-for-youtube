# Genius pour YouTube

Extension Chrome Manifest V3 qui recherche les paroles Genius pour la vidéo YouTube en cours.

## Installation locale

1. Créer un client sur [Genius API Clients](https://genius.com/api-clients) et copier le token.
2. Remplacer `YOUR_GENIUS_ACCESS_TOKEN` dans `popup.js` par ce token, uniquement dans ta copie locale.
3. Ouvrir `chrome://extensions`, activer le mode développeur et cliquer sur **Load unpacked**.
4. Sélectionner ce dossier.

Le dépôt public ne contient volontairement aucun token, identifiant ou chemin personnel.
